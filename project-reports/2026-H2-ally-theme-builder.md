# Project Overview
The Accessibility Theme Builder project is a web application that allows users to build a design system (color palette, fonts, styling, etc) for their application that is WCAG 2.1 AA compliant in both light and dark modes using an Atomic Accessibility Design methodology.  The application looks at the design system as a whole and will only allow the user to see and act on options that will maintain this level of compliance.  The output from the build experience can be JSON Figma tokens or CSS and a Material UI theme.  When a web application uses the theme for its components and the CSS vars across its UI, it will enjoy the benefits of being WCAG 2.1 AA compliant and the diversity, equity, and inclusion that WCAG promotes.
